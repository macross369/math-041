使用省略符號「~~」
省略符號設定值 (省略門檻):

從 0 出發，第一格標記省略符號「~~」，並由此設定值向上累加刻度。

為什麼需要省略符號？

「大數值長條圖」省略符號 ( ~~~ ) 效果即時對比

當資料得票數都很高（例如都在 900~1300 票）時，若從 0 逐一畫到 1300，長條圖差異難以觀察；使用省略符號可大幅提升可讀性！

❌ 未使用省略符號 (從 0 畫到 1300) 高低差距極不明顯

📢 觀察結果：空間大量被 0~900 的空白浪費，各景點得票的細微差異（如 980 與 1040）幾乎看不出來。

✅ 從 0 起始並於第一格使用「~~」波浪線 對比清晰明確

🎉 觀察結果：從 0 向上第一格省略 0~900 無資料區間，重點集中於 900~1300 的數據變化，圖表既精確又美觀！
